# ElyxBuilder

CLI tool for building Elyx plugins.

Fork of [shareui/ElyxBuilder](https://github.com/shareui/ElyxBuilder).

## Installation

```
pip install elyxbuilder-cli
```

## Requirements

- Python >= 3.10
- Python 3.11 — required only for `.pyc` compilation
- pyzipper — required only for archive encryption
